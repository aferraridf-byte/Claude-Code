# Identidade visual — Intex Bank

Repositório de referência da marca Intex Bank (international exchange bank) para qualquer
documento, apresentação ou peça gerada neste projeto.

## Logos (`logos/`)

| Arquivo | Uso |
|---|---|
| `intex-horizontal-cor.png` | Padrão para documentos (cabeçalho, capa, rodapé). Fundo claro. |
| `intex-vertical-cor.png` | Capas, slides de abertura, peças quadradas. Fundo claro. |
| `intex-horizontal-negativo.png` | Fundo escuro (texto branco + símbolo verde). |
| `intex-vertical-negativo.png` | Fundo escuro, versão vertical. |

Todos são PNG 2000 px de largura com fundo transparente. Nas versões negativas o texto é branco:
em fundo claro parecem só o símbolo.

## Paleta usada nos documentos institucionais

| Token | Hex | Uso |
|---|---|---|
| Azul-marinho Intex | `141D32` | Títulos, cabeçalho de tabela, texto de marca |
| Verde Intex (logo) | `97E800` aprox. | Símbolo |
| Verde de destaque (docs) | `92C024` | Filetes, "CONFIDENCIAL — USO INTERNO", bordas de destaque |
| Verde-claro de fundo | `F2F8E6` | Caixa de veredito |
| Cinza-azulado de fundo | `EEF1F5` | Coluna de rótulos da ficha |
| Texto corrido | `222222` | Corpo |
| Cinza secundário | `5A5F6B` | Rodapé, legendas |
| Borda de tabela | `C9CCD3` | Grades |

Fonte dos documentos: **Trebuchet MS**.
